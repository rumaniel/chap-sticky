# 찹! 찐득이 — 자체 제작 리소스 카탈로그

전부 코드 생성 (외부 파일 0) · 아트 = Canvas 드로잉 · 사운드 = WebAudio 신스.

> **추적 규칙**: 리소스(아트·사운드·UI) 변경 시 이 문서의 해당 항목·상태 표를 같이 갱신한다.
> 평가 태그 — ✅ 유지 / 🔶 개선 후보 / 📝 메모.
> 캡처 이미지는 `docs/shots/` (재촬영 파이프라인: 헤드리스 캔버스 렌더 → upload_server).
